# School Calendar Year Booking System

A Java terminal program where students, faculty and staff request a venue, date and time for a school event, and the Admin approves or rejects each request; approved events show in the school calendar.

## How to run

1. Clone this repository.
2. Open `Main.java` and run.

The `.txt` data files are created in the project's main folder the first time the program saves. They are not committed (see `.gitignore`).
